# Security Policy

Found a security or privacy vulnerability in SpyEye? Please don't open a public issue — report it privately so it can be fixed before anyone else can find and use it.

**Preferred:** [Report a vulnerability](https://github.com/spyeyeapp/spyeye-android/security/advisories/new) through GitHub's private advisory form.
**Alternative:** email [security@spyeye.app](mailto:security@spyeye.app).

Include what you found, steps to reproduce, and the potential impact. We'll acknowledge your report and keep you updated as we investigate.

Only the latest release receives security fixes.
